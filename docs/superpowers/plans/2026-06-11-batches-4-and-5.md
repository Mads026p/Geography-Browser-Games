> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Correct aircraft presentation and reduce globe rendering cost without changing game rules or replacing the established globe renderer.

**Architecture:** Extract small pure helpers for flight visual orientation and render policy so behavior is testable outside the browser. Keep physics and geographic projection in `app.js`, Three.js model drawing in `plane-renderer.js`, and use per-frame caches around the existing tile renderer.

**Tech Stack:** Browser JavaScript, Canvas 2D, Three.js, Node.js ESM, `node:test`.
