# GeoSphere Batches 6 and 7 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reduce `app.js` coupling, preserve borders while rotating, and add a deterministic one-attempt Daily Challenge with achievements and a flag gallery.

**Architecture:** Batch 6 extracts immutable content and canonical mode metadata into browser-global modules with Node exports, leaving runtime behavior in `app.js`. Batch 7 adds a pure progression/daily engine and thin UI integration, reusing existing country and trivia sources without coupling five existing mode state machines.

**Tech Stack:** Browser JavaScript, Canvas 2D, HTML/CSS, Node.js ESM tests using `node:test`, localStorage through `GeoSphereSupport`.
